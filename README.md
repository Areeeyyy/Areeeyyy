## Featured project

### LungLens

Pneumonia classification on chest X-ray images using a convolutional neural network.

You upload a chest X-ray. The model classifies it as **NORMAL** or **PNEUMONIA**. It then runs Grad-CAM (Gradient-weighted Class Activation Mapping) over that prediction and returns a heatmap of the regions it weighted most heavily while deciding.

The label tells you what the model decided. The heatmap shows you where it was looking. That second part is what makes the result reviewable rather than opaque, and it is the reason the project exists in this shape.
